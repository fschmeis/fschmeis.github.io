# Felix Schmeißer – persönliche Website

Statische Seite ohne Build-Schritt: `index.html`, `style.css`, `main.js`.
Schriften (Instrument Serif, Geist, Geist Mono, SIL Open Font License) liegen in `fonts/`, damit keine Verbindung zu Google aufgebaut wird.

Lokal ansehen: `python3 -m http.server` im Ordner starten und http://localhost:8000 öffnen.
